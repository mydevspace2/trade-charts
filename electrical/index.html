How to use the electrical references together

A typical branch circuit job touches several tools in order. First pick the conductor from the ampacity tables, then check the conduit with the conduit fill calculator, and finally plan the bends with the offset multiplier chart.

Workflow for a new circuit

  1. Find the load in amps and apply the 125% rule for continuous loads.
  2. Choose a wire size from the ampacity table at the correct temperature column for your terminations.
  3. If more than three current-carrying conductors share a raceway, apply derating. See derating bundled conductors.
  4. Check voltage drop on long runs, and read the detached garage subpanel example.
  5. Size the conduit by fill and the box by volume; see box fill step by step.

These pages reproduce published NEC table values for reference. Always verify against the edition of the NEC adopted where you work and follow your local inspector.

Common electrical mistakes these tools prevent

  • Using the 90 °C ampacity column for a circuit whose terminals are rated 60 °C or 75 °C; read the temperature columns explained.
  • Forgetting the equipment ground when counting conduit fill.
  • Ignoring voltage drop on long runs such as a detached garage feeder.
  • Choosing a conduit by fill only, without checking which raceway type suits the install.

When you bend the conduit, the offset multiplier chart gives mark spacing and shrink for each angle.

Where to start

Most residential jobs begin with the load: add up the amps, choose the wire from the ampacity chart, then size the conduit with the fill calculator, check the length against the voltage drop calculator and pick the box with the box fill calculator. Everything here reproduces published NEC values, so confirm the edition adopted in your area and your inspector’s local amendments before you buy materials.

New to the tables? Start with the 40% fill rule, the 3% voltage drop guideline and box fill step by step.

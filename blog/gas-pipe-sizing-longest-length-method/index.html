How to Size Gas Pipe: The Longest Length Method

Guide · Updated November 13, 2026

The IFGC sizing tables make gas pipe sizing a lookup: total load, longest length, read the row. Here is the method most inspectors expect, with an example.

Step 1: total the load

Add the maximum input from each appliance rating plate. Example house: furnace 80,000 Btu/h, water heater 40,000, range 65,000, dryer 22,000 = 207,000 Btu/h.

Step 2: convert to the table units

Natural gas tables are in cubic feet per hour (CFH). Divide by the heating value of the gas; 1,000 Btu/ft³ is a common assumption, but your utility can give the actual value. 207,000 ÷ 1,000 = 207 CFH. Propane tables in the IFGC are already in thousands of Btu/h (207 MBH).

Step 3: find the longest length

Measure from the point of delivery (meter or second-stage regulator) to the most remote appliance. Say that is the dryer at 60 ft. Under the longest length method, the 60 ft row is used for every section of the system.

Step 4: size each section

Using IFGC Table 402.4(2) (Schedule 40 iron, under 2 psi, 0.5 in. w.c. drop), 60 ft row: 1/2 in = 65 CFH, 3/4 in = 137, 1 in = 257, 1-1/4 in = 528.

Sections that carry several appliances are sized for their combined load. If the load falls exactly on a table value, that size is acceptable; if the length falls between rows, use the longer row.

Things to confirm

  • The table must match your gas, inlet pressure and design pressure drop.
  • Many fittings add equivalent length (IFGC Appendix A); CSST tables already include four bends and two fittings.
  • CSST sizes are by EHD, which varies by manufacturer.
  • Plan capacity for future appliances (generator, pool heater, outdoor kitchen).

Propane version of the same house

For propane on the IFGC tables you do not convert to CFH: the tables are in thousands of Btu/h. The same 207,000 Btu/h house is 207 MBH. Use the propane table that matches your system (for example the 11 in. w.c. low-pressure table downstream of the second-stage regulator) and the same longest-length row. Our propane pipe sizing chart has those tables.

Common mistakes

  • Measuring only to the nearest appliance instead of the most remote one.
  • Using a table for a different gas, pressure or pressure drop.
  • Forgetting future appliances such as a generator or pool heater.

Branch length method

The IFGC also allows a branch length method (402.4.2), which sizes each section using the length from the point of delivery to the most remote outlet served by that section, and a hybrid pressure method for CSST systems (402.4.3). These can allow smaller pipe on some branches but take more measuring; the longest length method is simpler and always conservative.

Frequently asked questions

What is the longest length method?
You measure from the point of delivery to the most remote appliance and use that one length row of the IFGC table for every section of the system, each sized for the load it carries.
How do I convert Btu/h to CFH for natural gas?
Divide the Btu/h load by the heating value of the gas. 1,000 Btu per cubic foot is a common assumption; your utility can give the actual value.
What if my length falls between two table rows?
Use the next longer row. If the load falls exactly on a table value, that pipe size is acceptable.
Are propane tables in CFH?
No. The IFGC propane tables list capacity in thousands of Btu per hour (MBH), so you can use the appliance input directly.
Do fittings add length?
Yes, fittings add equivalent length (IFGC Appendix A). CSST manufacturer tables typically already include an allowance for bends and fittings.

Example. A 120,000 Btu/h propane load is 120 MBH. With a 50 ft longest run, the first size in the 50 ft row with at least 120 is EHD 25.

CSST sizes are given as EHD (equivalent hydraulic diameter) flow designations; check the manufacturer’s EHD for its tube sizes, because the same nominal size can differ between brands. The table includes losses for four 90-degree bends and two end fittings.

How to size gas pipe with this table

  1. Add up the maximum input (nameplate Btu/h) of every appliance the section serves.
  2. Propane tables are in thousands of Btu/h; use the load directly.
  3. Measure the length from the meter or regulator outlet to the farthest appliance; use the next longer row if your length falls between rows.
  4. In that row, choose the first pipe size whose capacity equals or exceeds the load. Repeat for each branch with its own load, using the same row.

Use this table only for the exact gas, pressure and pressure drop in its heading; a different design pressure drop needs a different table. Low-pressure (under 2 psi) systems usually serve appliances at about 7 in. w.c. natural gas or 11 in. w.c. propane; 2 psi and 5 psi systems need a line regulator ahead of the appliances.

Frequently asked questions

What is the longest length method?
IFGC 402.4.1: find the length from the point of delivery to the most remote outlet and use that single length row of the table to size every section of the system, each for the load it carries.
How do I convert Btu/h to CFH?
Propane tables in the IFGC are already in thousands of Btu per hour, so a 120,000 Btu/h load is 120 in the table.
Do fittings count?
The IFGC tables are based on straight pipe; Appendix A suggests adding equivalent length for runs with four or more fittings. CSST tables already include four 90° bends and two end fittings; add 1.3 ft for each extra bend or fitting.

Privacy Policy

Short version: we do not collect personal data. No analytics, no advertising, no cookies, no tracking scripts.

What happens when you visit

Pages are static files served by GitHub Pages. Like any web host, GitHub may log technical data such as your IP address for security and operations; see GitHub’s privacy statement. We do not receive or use those logs for tracking.

Calculators

All calculations run in your browser. Values you type are never sent to a server. A small amount of data (for example the unit you last selected) may be stored in your browser’s local storage so the page remembers it; it never leaves your device and you can clear it in your browser settings.

Email

If you email us, we use your address only to reply.

Changes

If this ever changes (for example if we add privacy-friendly analytics), we will update this page first. Last updated November 13, 2026.
